# Pilot task — codebase map (small, read-only-plus-one-file)

Read this repository (a Godot 4.4 Android game slice) and create ONE new file: `docs/CODEBASE_MAP.md`.

It must contain:
1. A section per script in `scripts/` — file name, what it is responsible for, and its key functions/signals.
2. A section listing the asset groups under `assets/` (models, textures, plates) and what each group is used for — from file NAMES and directory structure only; do not open any image or model file.
3. The export presets from `export_presets.cfg` (name + platform).
4. The project settings from `project.godot` that matter for Android/touch input.

Rules: do NOT modify any existing file. Only create `docs/CODEBASE_MAP.md`. Keep it factual — describe only what the files actually contain.
